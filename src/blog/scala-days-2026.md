# Typelevel Talks at Scala Days 2026

[Scala Days](https://scaladays.org/) 2026 recently wrapped up, and [talk videos](https://www.youtube.com/@ScalaDaysConferences) are already up! Two of the talks touched on the work of the Typelevel Foundation:

* [A Typelevel Prospectus](https://www.youtube.com/watch?v=Zob6LT7s4n8): Arman Bilge gives an overview of the Typelevel organization, what we do, and where we are going.
* [Securing Typelevel: Lessons from the GitHub SOS Fund](https://www.youtube.com/watch?v=Og1z8A3C4Rg): Antonio Jimenez talks about his experience working with the GitHub Secure Open Source Fund to help [secure Typelevel projects](github-soss-fund-2026.md).

Some other speakers are making use of Typelevel libraries:

* [Caching in Scala using Cats Ref](https://www.youtube.com/watch?v=UeOeN02HVWA): Katrina Petrevice discusses building a caching system using Cats Effect [Ref](https://typelevel.org/cats-effect/docs/std/ref).
* [Type-Driven AI: High quality Scala code with LLM](https://www.youtube.com/watch?v=83yTwPq_0gc): Giovanni Ruggiero explores various tools to improve the quality of LLM generated Scala code, including [ScalaCheck](https://scalacheck.org/) and [otel4s](https://typelevel.org/otel4s/).

Some of our Summer of Code participants gave talks about their work:

* [A Maiden Voyage into Open Source, Datatypes, and Scala](https://www.youtube.com/watch?v=w9x-h2mBKOE): L Denney speaks about data structure optimization and getting started with open source contributions.
* [Cats Go Wasm/WASI: Typelevel on Server-side WebAssembly](https://www.youtube.com/watch?v=SLha2oF0p90): Mariusz Jakoniuk goes over prototyping Cats Effect and FS2 IO primitives for the WASI 0.2 API.
* [Inline Traits for Specialization](https://www.youtube.com/watch?v=xbtoso_F5-Q): James You describes a new scheme for [trait specialization in Scala 3](https://github.com/scala/improvement-proposals/pull/138).

Two of our [Typelevel Traverses Europe](traverses-europe-2026.md) speakers also gave talks at Scala Days:

* [Is metaprogramming just functional programming?](https://www.youtube.com/watch?v=ZXsh6jtuCFQ): Kathryn Frid explores the line between metaprogramming and functional programming, and will be speaking at Typelevel Traverses Copenhagen on October 22.
* [Stop testing, start proving](https://www.youtube.com/watch?v=75CYSpYzhGY): Valentin Bergeron gives a brief version of his Typelevel Traverses Berlin talk about formal verification in Scala.
